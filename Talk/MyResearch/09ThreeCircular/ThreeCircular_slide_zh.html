論文背景與核心貢獻總覽： 本論文（林慶泉、楊舜評、薛念林；發表於 Fundamenta Informaticae，IOS Press，預印本標註 2008／正式刊登 2009，頁 1–15）提出一種空間域「三環像素（Three-Circular-Pixel, TCP）」差值擴張可逆式資訊隱藏技術。 核心創新： 在 Tian (2003) 經典的差值擴張（DE）演算法中，影像被切分為不重疊的兩像素對，導致單層藏量上限受限於 0.50 bpp，且每擴張兩個差值最多需更動 4 個像素。本研究將影像劃分為三像素環狀區塊，並以區塊內最大值像素作為共享中心錨點；當調高此最大值像素時，其與最小值及中間值像素的「兩個差值」會同步擴大。此設計將可用像素對數量由 N/2 提升至 floor(2N/3)（單層上限 0.67 bpp），且最多僅修改 3 個像素，有效降低均方誤差（MSE）並全面提升 PSNR 與藏量表現。

論文結構導讀： - 第一節（Introduction，頁 2–3）：說明醫療診斷等零失真領域對可逆式隱藏的需求，並系統性回顧四大技術路線：LSB 壓縮（Fridrich 等）、廣義 LSB 量化殘差壓縮（Celik 等）、差值擴張（Tian 及其衍伸研究）與直方圖平移（Ni 等、Lin 等）。 - 第二節（Difference Expansion，頁 3）：以實例回顧 Tian (2003) 兩像素差值擴張與溢位位置圖（Location Map）需求。 - 第三節（The Proposed Scheme，頁 3–11）：詳述 TCP 區塊定義與雙差值擴張（3.1）、正式嵌藏流程與中心像素對稱性（3.2）、盲萃取還原與門檻 1 <= T <= 127 限制證明（3.3），以及 3x6 影像完整範例（3.4）。 - 第四節（Experimental Results，頁 11–14）：以 Java 實作比較 Lena、Baboon、Airplane、Boat 四張 512x512 灰階影像之 PSNR 與藏量曲線，並透過 Table 1 分析不同門檻 T 下的 JBIG 壓縮率。 - 第五節（Conclusions，頁 13–14）：總結三環像素雙差值擴張的理論優勢與實證成果。

理論背景與文獻脈絡（第一節）： 可逆式（無失真）資訊隱藏要求接收端在萃取秘密訊息後，能位元精確地還原原始掩護影像。 1. Fridrich 等 [1, 2] 透過無失真壓縮 LSB 位元平面騰出藏入空間，藏量取決於影像紋理壓縮效率。 2. Celik 等 [3] 提出廣義 LSB 修改：先對像素 x 量化為 Qx = q * floor(x/q)，將殘差 r = x mod q 壓縮後連同秘密訊息轉為 q 進位符號 s_i，再以 Qs = Qx + s_i 嵌入，萃取時取 s_i = Qs mod q 並解壓殘差還原。 3. Ni 等 [12] 利用影像直方圖峰值 M 與零值點 m 平移像素；因單純灰階峰值有限，Lin 等 [13] 改採兩像素區塊差值直方圖平移以擴大藏量。 4. Tian [4] 於 2003 年開創差值擴張（DE），後續 Chang & Lu [6] 與 Thodi & Rodriguez [7] 透過預測誤差減少擴張失真。本論文則從區塊拓撲結構切入，以三環像素共享中心峰值突破兩像素對的容量與失真雙重瓶頸。

Tian 差值擴張細節解析（第二節）： 在 Tian (2003) 方法中，兩像素差值 h = x - y 經擴張後成為偶數 h' = 2h，其最低位元（LSB）固定為 0，構成可逆藏入空間。嵌入訊息位元 b in {0, 1} 時更新 x'' = x' + b。 還原階段先求 b = |x'' - y'| mod 2 與原差值 h = floor((x'' - y')/2)，再代入： - x = x'' - b - floor(h/2) = 30 - y = y' + floor((h + 1)/2) = 33。 溢位與位置圖問題： 若像素值接近邊界（如 x=235, y=250），直接擴張將導致像素值超過 255（過飽和）。因此必須維護一張長度為 floor(N/2) 位元的位置圖記錄各像素對是否擴張，並於嵌入前無失真壓縮。 TCP 方案之對比優勢： 如上方向量圖所示，針對 (24, 28) 與 (28, 26) 兩組差值，Tian 方法分別擴張為 (22, 30) 與 (29, 25)，四個像素全數改動，平方誤差總和為 (-2)^2 + 2^2 + 1^2 + (-1)^2 = 10；TCP 將三像素 (24, 28, 26) 共用中心最大值 28，擴張後得 (22, 30, 26)，第三像素 26 完全不動，平方誤差降至 8。

TCP 區塊定義與雙差值擴張機制（第三節與 3.1 節）： 原始三像素區塊 [a_i, b_i, c_i] 依由左至右、由上而下掃描（可採 1x3、3x1 或 L 型排列，見圖 1a）。將三像素排列於有向環上（圖 1b），以最大值像素 y_i 為邏輯中心，x_i 為邏輯左鄰、z_i 為邏輯右鄰。 決定性同值判定規則： 當 y_i = x_i 或 y_i = z_i 時，嚴格規定「掃描順序較早者」為中心像素 y_i（例如 [26', 20, 26] 轉為 (26, 26', 20)）。此規範確保編碼端與解碼端產生完全一致的 TCP 元組。 數值驗證流程（3.1 節）： 對於 (24, 28, 26)，因 h_i1 = 4 >= h_i2 = 2，先對較大差值 h_i1 進行對稱擴張：x'_i = 24 - 2 = 22、y'_i = 28 + 2 = 30，再由 z'_i = y'_i - 2*h_i2 = 30 - 4 = 26 求得第三像素，剛好維持 26 不變。 嵌入位元 b_1 = 0, b_2 = 1 時自 x'_i 與 z'_i 分別減去 b_1, b_2 得偽裝區塊 (22, 30, 25)。接收端計算 h''_i1 = 8、h''_i2 = 5，取 mod 2 得 b_1 = 0, b_2 = 1，取 floor(/2) 得原差值 4 與 2，即可精確還原 (24, 28, 26)。文中另列舉 (24, 28, 23)、(24, 28, 25)、(24, 28, 24) 等區塊，其 MSE 皆顯著低於 Tian 兩組雙像素區塊。

形式化可擴張與可更動理論（3.2 節）： 針對 8-bit 灰階像素（範圍 0..255），擴張差值並再減去訊息位元 b in {0, 1} 後，絕對不可發生小於 0（下溢）或大於 255（溢位）。條件式中 `x_i - floor(h_i1/2) - 1 >= 0` 的 `- 1` 正是為後續嵌入位元 `1` 預留安全邊際。 重要結構推論： 若 h_i1 >= h_i2，則必有 x_i <= z_i。當較大差值 h_i1 可擴張時，代表 y'_i <= 255 且 x'_i - 1 >= 0；由於 z'_i = y'_i - 2*h_i2 >= y'_i - 2*h_i1 = x'_i，故 z'_i - 1 >= x'_i - 1 >= 0 必然成立，因此較小差值 h_i2 自動保證可擴張。 可更動（Changeable）條件之意義： 若對未擴張的差值 h'_i1 進行 LSB 置換：當 h'_i1 為奇數時，將其 LSB 改為 0 只需把 x'_i 加 1（因 x'_i < y'_i <= 255，必不溢位）；當 h'_i1 為偶數時，將 LSB 改為 1 需把 x'_i 減 1，故僅在 x'_i > 0 時合法。唯有「差值為偶數且 x'_i = 0」時才不可更動。

完整八步驟嵌藏演算法詳解（3.2 節）： 1. 將 N 像素原圖劃分為不重疊三像素區塊並轉換為 TCP 區塊 (x_i, y_i, z_i)。 2. 依門檻 T 將各差值歸類至 EN 或 CN，並按表列四類互斥情況（2.1 至 2.4）更新像素值。 3. 建立長度固定為 floor(2N/3) 位元的位置圖 L：若 h_i1 in EN 則設 e_{2i} = 1（否則 0），h_i2 對應 e_{2i+1}。 4. 計算調整後差值 h'_i1, h'_i2，收集所有屬於 CN 之可更動差值原始 LSB 存入控制串列 C。 5. 以 JBIG 無失真壓縮 L 與 C 成為 LC*。因 |L| = floor(2N/3) 可由影像尺寸直接推算，不需額外紀錄，僅需 16 位元儲存 |LC*| 與 17 位元儲存 |C|。 6. 串接完整位元流 S = |LC*| || |C| || LC* || U。 7. 依據式 (1) 與式 (2)，將 S 的位元盲目覆寫至所有可更動差值（涵蓋已擴張的 EN 與未擴張的 CN）的 LSB：若 h'_i1 為偶數，減去 b_i1 使新差值 LSB 等於 b_i1；若 h'_i1 為奇數，改為加上 (1 - b_i1)，同樣精確將新差值 LSB 設為 b_i1。 8. 將各偽裝 TCP 區塊 (x''_i, y'_i, z''_i) 逆向旋轉回原始掃描座標，輸出偽裝影像。

數學性質與邊界條件嚴謹證明（3.2 與 3.3 節）： 1. 中心像素對偶性（圖 3，頁 7–8）： 給定原始區塊 [10, 12, 20]，以最大值 20 為中心得 TCP (12, 20, 10)，h_i1 = 8, h_i2 = 10；擴張後 h'_i1 = 16, h'_i2 = 20，得 (9, 25, 5)，還原空間排列為 [5, 9, 25]。 若改以最小值 10 為邏輯中心，兩差值為 h_i2 = 20 - 10 = 10 與 h_i3 = 12 - 10 = 2。因線性關係 h_i2 = h_i1 + h_i3 成立，倍增 h_i2 至 20 必然同時將 h_i3 擴張至 4，產生完全相同的像素 [5, 9, 25]。故論文選定最大值為中心不失一般性。 2. 門檻 1 <= T <= 127 之必要性證明（3.3 節，頁 10）： 當 T = 0 時，差值 h = 1 不會被擴張而落入 CN。若對 [29, 29, 30] 嵌入位元「10」，因 h'_i2 = 1 為奇數且嵌入位元為 0，式 (2) 會將 z'_i = 29 加 1 變為 30，使偽裝區塊成為 [30, 29, 30]。此時第一與第三像素並列最大，解碼端按掃描順序誤判第一像素為 y'_i，導致提取位元反轉為「01」。限定 T >= 1 即可完全消除此結構歧義。

無失真解碼與像素還原機制（3.3 節，頁 8–10）： TCP 方案在萃取階段的一大優點是「完全盲萃取」：由於所有在嵌藏階段被擴張的差值（EN）在偽裝影像中必定仍滿足可更動條件，解碼器無須事先知道位置圖 L，即可透過式 (3)–(4) 掃描全圖直接萃取出完整位元流 S。 取得 S 後，解碼器先解析固定長度的 |LC*|（16 位元）與 |C|（17 位元），再以 JBIG 解壓縮 LC* 得到： - L：長度固定為 floor(2N/3) 位元的位置圖，用以區分已擴張（e=1）與未擴張（e=0）差值。 - C：所有 CN 差值在覆寫前的原始 LSB。 步驟 6 之還原邏輯以「較大差值」為核心驅動： - 當雙差值皆擴張（6.1）時，由較大差值率先還原中心最大值 y_i 與最小值像素（x_i 或 z_i）；一旦 y_i 確定，剩餘之中間像素直接由 y_i 減去折半後的較小差值即可無誤求得。 - 凡未擴張的可更動差值（6.2–6.4），只需比對控制位元 c 與萃取位元 b：若 c=1, b=0 則減 1；若 c=0, b=1 則加 1；相同則不變。全圖可達 100% 位元精確還原。

3x6 影像逐區塊數值追蹤（3.4 節，頁 10–11）： 圖 4 以一張 3 列 x 6 行（共 18 像素、6 個三像素區塊、12 組像素對）的小型灰階影像演示門檻 T = 4 的完整生命週期： - 區塊 0：[62, 60, 59] -> TCP (59, 62, 60) -> 擴張 (58, 64, 60) -> 嵌入 "10" -> 偽裝 (57, 64, 60) -> 原始排列 [64, 60, 57]。 - 區塊 1：[60, 58, 61] -> TCP (58, 61, 60) -> 擴張 (57, 63, 61) -> 嵌入 "00" -> 偽裝 (57, 63, 61) -> [61, 57, 63]。 - 區塊 2：[64, 63, 60] -> TCP (60, 64, 63) -> 擴張 (58, 66, 64) -> 嵌入 "11" -> 偽裝 (57, 66, 63) -> [66, 63, 57]。 - 區塊 3：[61, 59, 20] -> TCP (20, 61, 59)：h_31 = 41 > 4（CN，e_6 = 0）、h_32 = 2 <= 4（EN，e_7 = 1）-> 擴張 (20, 62, 58) -> 嵌入 "01" -> 偽裝 (20, 62, 57)。注意 h'_31 = 62 - 20 = 42 為偶數，其原始 LSB = 0 存入 C。 - 區塊 4：[60, 65, 57] -> TCP (60, 65, 57)：h_41 = 5 > 4、h_42 = 8 > 4（皆為 CN，e_8 = e_9 = 0，原始 LSB 1, 0 存入 C）-> 嵌入 "01" -> 偽裝 (61, 65, 56)。 - 區塊 5：[57, 59, 55] -> TCP (57, 59, 55) -> 擴張 (57, 61, 53) -> 嵌入 "10" -> 偽裝 (56, 61, 53)。 最終 12 位元完整位元流 S 被盲萃取並解壓，全部 18 個像素與圖 4(a) 逐一吻合，無任何失真。

實驗設計與對照控制（第四節，頁 11–12）： 為確保公平比較，作者於同一 Windows 平台以 Java 實作本論文方法與 Tian [4] 差值擴張法，並選用四張具代表性的 512x512 8-bit 灰階標準影像： - Lena（平滑人像與適度邊緣） - Baboon（高頻毛髮與鬍鬚紋理，檢驗高複雜度影像之極限） - Airplane（大面積平滑天空與機身） - Boat（水面平滑區與船桅細節並存） 標頭與壓縮開銷細節： 對於 N = 262,144 像素之影像，位置圖 L 長度恆為 floor(2 * 262,144 / 3) = 174,762 位元，解碼端可由影像長寬直接推知，故僅需 16 + 17 = 33 位元標頭記錄 |LC*| 與 |C|，將 L 與 C 合併交由 JBIG 壓縮後串接秘密訊息 U 一併嵌入。

率失真（Rate-Distortion）效能分析（第四節，圖 6，頁 12–13）： 圖 6 呈現四張 512x512 影像在單層嵌藏下的 PSNR（dB）與藏量（bpp）對比曲線： - Lena（圖 6a）：TCP 曲線從約 0.14 bpp 一路領先至 0.666 bpp（T=127 時為 32.13 dB），而 Tian 方法在 0.50 bpp 前即已觸頂。 - Baboon（圖 6b）：高紋理影像雖使兩種方法之 PSNR 隨藏量下降較快，但 TCP 在同等藏量下持續保持較高 PSNR，且藏量延伸超越 0.65 bpp。 - Airplane（圖 6c）與 Boat（圖 6d）：皆展現一致的畫質與藏量雙重優勢。 圖表橫軸定義備註： 論文第四節（頁 12）明確說明，圖 6 橫軸之 embedding capacity 係指可擴張集合 EN 所提供之總藏量空間 |E| 除以總像素數 N；而扣除 JBIG 壓縮後輔助資訊 |LC*| 之淨藏量分析則詳列於表 1。

表 1 量化解讀與例外案例討論（3.4 與第四節，頁 11–14）： 表 1 精確揭示了 Lena（512x512，總可更動對數 |E| + |C| = 174,762）在不同門檻 T 下的權衡曲線： - 當 T = 1..7 時，JBIG 壓縮後的 |LC*| 介於 299,336 至 189,000 位元，皆超過全圖總可更動空間 174,762 位元，無法再容納使用者訊息 U。 - 自 T = 8 起，|LC*| 降至 169,368 位元，開始釋出正淨藏量（同時保有 41.56 dB 高 PSNR）。 - 當 T = 20 時，淨使用者藏量突破 108k 位元（約 0.41 bpp 淨藏量），PSNR 為 37.07 dB；當 T = 127 時，|LC*| 僅佔 2,512 位元（壓縮比 69.6 倍），淨藏量超過 172,000 位元（約 0.66 bpp），PSNR 維持 32.13 dB。 誠實揭露局部 MSE 例外（頁 11）： 當同一 TCP 區塊中 h_i1 遠大於 h_i2（如 (40, 80, 76)，h_i1 = 40、h_i2 = 4），調高中心像素 y_i 達 +20 時，為維持 h'_i2 = 8 必須將 z_i 由 76 拉升至 92（位移 +16），導致該局部區塊 MSE 高於 Tian 方法。作者在文中主動剖析此現象，並指出自然影像的空間平滑特性使整體效能仍顯著優於基準法。

結論綜整（第五節，頁 13–14）： 本研究提出的三環像素（TCP）差值擴張可逆式資訊隱藏技術，透過三項互補設計突破經典兩像素差值擴張的限制： 1. 共用峰值雙差值擴張：調高三像素環狀區塊內的最大值像素，即可同步擴大兩組差值，既減少每對位元修改之像素數量，亦將單層藏量上限推升至總像素數的三分之二（0.67 bpp）。 2. 決定性可逆機制：在 1 <= T <= 127 門檻規範下，先還原較大差值所對應之最大值與最小值像素，再計算剩餘像素與最大值之差即可精確復原原始區塊。 3. 實證效能驗證：在 Lena、Baboon、Airplane 與 Boat 四張標準影像上，TCP 方案在 PSNR 視覺品質與藏量上限兩項指標上皆顯著優於 Tian (2003) 基準方法。
