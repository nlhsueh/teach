Bibliographic & Research Overview: This paper (Lin, Hsueh, & Shen, Fundamenta Informaticae 84, 2008, pp. 1–12, IOS Press) proposes a high-visual-quality adaptive binary data hiding algorithm for grayscale host images. Core Research Idea: Conventional spatial-domain methods such as simple LSB substitution and Optimal Pixel Adjustment Process (OPAP) embed a fixed integer number k of bits per pixel (effective alphabet size q = 2^k). When the target embedding capacity C lies between integer bit counts (e.g., 1.5, 2.25, or 3.375 bpp), fixed-k methods must either waste pixel capacity or abruptly mix k-bit and (k+1)-bit embeddings. The proposed scheme instead divides the binary message M into two segments and decomposes them into n and n-1 types of variable-length elementary sub-messages (n >= 3) using a Directory of Elementary Messages (DEM). Each host pixel then embeds one sub-message by shifting to its nearest congruence class modulo n (or n-1), bounding pixel distortion to at most floor(n/2).

Structural Navigation: The paper is organized into five sections: Section 1 introduces image steganography and surveys spatial-domain alternatives; Section 2 reviews simple LSB substitution and Chan & Cheng's OPAP [9]; Section 3 formally defines DEM_t(n), the expected capacity formula EC_n, the 8-step adaptive two-segment embedding algorithm, the modulo extraction procedure, and a complete 4x4 grayscale worked example; Section 4 reports Java/Windows XP experimental comparisons over 100 random messages per capacity on four 512x512 test images; Section 5 summarizes the bounded-distortion guarantee and conclusions.

Research Motivation (Section 1): In spatial-domain image hiding, both direct LSB replacement and pixel-value adjustment alter host pixels and introduce distortion. While replacing k LSBs is straightforward, k is restricted to integers (typically k <= 4 for acceptable visual quality). Consequently, the number of representable states per pixel jumps exponentially (2, 4, 8, 16). By generalizing per-pixel states to arbitrary integers n >= 3 via prefix-free variable-length sub-message directories (DEM) and splitting M across n and n-1 states, the algorithm continuously adapts to any payload length #(M) and host image size N while minimizing squared error.

Literature Positioning (Section 1): The paper contrasts five families of spatial-domain schemes: 1. PVD-based schemes [4, 5, 6]: Wu & Tsai (2003) map difference ranges {0-7, 8-15, 16-31, 32-63, 64-127, 128-255} to bit lengths {3, 3, 4, 5, 6, 7}, yielding < 1.6 bpp and < 42 dB. Wu et al. (2005) hybridize LSB for differences < 16 with PVD otherwise, and Chang et al. (2006) use preceding-pixel differences to select k. 2. Modulus-function schemes [7, 8]: Achieve OPAP-like adjustment for modulus q, but embedding raw binary streams forces q = 2^k. 3. Low-distortion low-payload schemes [10, 11]: Mielikainen's LSB matching lowers modification probability from 0.5 to 0.375 at 1 bpp; Zhang & Wang's Exploiting Modification Direction (EMD) embeds a (2R+1)-ary digit per R pixels with capacity at most log2(2R+1)/R bpp (max ~1.16 bpp at R=2). 4. Secret-image-only schemes [12, 13]: Exploit spatial smoothness of secret images and cannot embed arbitrary binary messages. Our algorithm bridges arbitrary binary payloads with fine-grained n-ary modulus embedding across wide capacities (1.0 to 3.875+ bpp).

Detailed Mechanics of Baselines (Section 2): Chan and Cheng (2004) [9] improve simple LSB substitution by observing that adding or subtracting 2^k preserves the k least significant bits (so extraction m = b'_i mod 2^k remains untouched) while pulling the stego-pixel closer to the original host pixel b_i. In Figure 1(a), with k = 2 and b_i = (01000011)_2 = (43)_16 = 67, embedding m = (00)_2 via simple LSB gives b'_i = (01000000)_2 = (40)_16 = 64, yielding d_i = -3. Because -4 < d_i < -2 and b'_i < 252, OPAP adds 2^2 = 4 to obtain (01000100)_2 = (44)_16 = 68, cutting |d_i| from 3 down to 1. Figure 1(b) shows the symmetric case: embedding (11)_2 into (44)_16 = 68 yields (47)_16 = 71 (d_i = +3), which OPAP pulls down by 4 to (43)_16 = 67 (d_i = -1). Our proposed Eqs. (2)-(3) generalize this exact nearest-neighbor adjustment from power-of-two moduli 2^k to arbitrary integers n >= 3.

Architecture Overview (Section 3): The proposed algorithm decouples binary message encoding from pixel-value modification through four stages: 1. Capacity & DEM Selection: Compute required capacity C = #(M)/N, select the smallest integer n >= 3 satisfying EC_n <= C < EC_{n+1}, and detect whether bit "1" or "0" dominates M to pick DEM_1(n) or DEM_0(n). 2. Two-Segment Decomposition: If |M_n| > N (due to bit-stream permutation variance), increment n by 1. Then split M = M'_n || M''_{n-1} so that |M'_n| + |M''_{n-1}| <= N with |M'_n| minimized (approximated by N * ER_n). 3. Nearest-Neighbor Pixel Embedding: Sequentially embed M'_n using modulus n and M''_{n-1} using modulus n-1 via Eqs. (2)-(3), guaranteeing |b''_i - b_i| <= floor(n/2) for non-oversaturated pixels. 4. O(1) Modulo Extraction: Recover sub-message index u = (b''_i mod n) + 1 (or mod (n-1)), look up m_u in the DEM, concatenate, and strip any trailing padding bits beyond #(M).

DEM Design & Mathematical Derivation (Section 3, Table 1, Eqs. 4–6): A Directory of Elementary Messages (DEM) is a complete prefix-free binary code of size n (constructed by recursively splitting a leaf m_u into m_u0 and m_u1). To maximize expected capacity EC_n for a uniform random binary message, every codeword length #(m_u) must differ by at most 1 bit—formally, floor(log2 n) <= #(m_u) <= ceil(log2 n) (Eq. 4). Proof sketch of Eq. (6): Let L = floor(log2 n). A balanced prefix-free set of n codewords splits (n - 2^L) leaves of length L into 2(n - 2^L) leaves of length L+1, leaving 2^L - (n - 2^L) = 2^{L+1} - n leaves of length L. Each leaf of length L has probability 2^{-L} and each leaf of length L+1 has probability 2^{-(L+1)}. Thus: EC_n = (2^{L+1} - n) * L * 2^{-L} + 2(n - 2^L) * (L+1) * 2^{-(L+1)} = L + (n - 2^L)/2^L = L - 1 + n / 2^L bpp. This yields the exact piecewise-linear capacity ladder: n=3 -> 1.5, n=4 -> 2.0, n=5 -> 2.25, n=6 -> 2.5, n=7 -> 2.75, n=8 -> 3.0, n=9 -> 3.125, n=10 -> 3.25, n=11 -> 3.375, n=13 -> 3.625, n=15 -> 3.875 bpp.

Algorithmic & Boundary Details (Section 3, Eqs. 2–3 & 7–8): Notice two crucial safeguards in Eq. (3): 1. Oversaturation protection: If b'_i > 255 (which can happen near 255 when u-1 > b_i mod n), Eq. (3) subtracts n so b''_i remains strictly within [0, 255]. Similarly, adding n requires b'_i <= 255 - n and subtracting n requires b'_i >= n. 2. Why two segments (n and n-1)? If step 4 increments n because |M_n| > N (or when C sits strictly between EC_{n-1} and EC_n), using DEM_t(n) across all pixels would leave many pixels unused while imposing larger max distortion floor(n/2) on every used pixel. Splitting M into M'_n (minimized) and M''_{n-1} (maximized) fills all N pixels while shifting as many pixels as possible into the tighter distortion envelope floor((n-1)/2). When n = 3, |M''_2| = 0 because n >= 3 is enforced.

Worked Example Verification (Section 3, Figures 2 & 3): Figure 2 illustrates why step 4 of the embedding algorithm checks |M_n| > N: even with fixed DEM_0(3) = {m1=1, m2=01, m3=00} and bit "0" dominating, the exact bit permutation changes how many 2-bit vs. 1-bit codewords occur across 8 pixels (14 bits = 1.75 bpp in (a), 12 bits = 1.50 bpp in (b), 11 bits = 1.375 bpp in (c)). Over random bit streams, however, the empirical average converges tightly to EC_n. In Figure 3, M has length 25 bits (14 ones, 11 zeros -> t = 1). Row-major scanning processes pixel 0 (value 45) with s_0 = "01" (m2 in DEM_1(4), u=2): b'_0 = 45 - (45 mod 4) + 1 = 45 (unchanged). Pixel 1 (value 47) embeds s_1 = "10" (m2 in DEM_1(3), u=2): b'_1 = 47 - (47 mod 3) + 1 = 46 (decreased by 1). At the final pixel 15 (value 43), the remaining single bit "1" is padded with "0" to form "10" (m2 in DEM_1(3)) because 43 mod 3 = 1 gives u = 2 directly with zero pixel modification.

Experimental Methodology (Section 4): Four classic 512x512 8-bit grayscale images spanning smooth to highly textured scenes (Lena, Baboon, Airplane, Pepper; N = 262,144 pixels each) serve as host images. To eliminate bias from any single bit-stream permutation, each data point in Tables 2, 3, and 4 averages the PSNR over 100 randomly generated binary messages. For non-integer capacities k in the LSB and OPAP baselines, the authors construct the optimal fractional baseline k = q * k_i + q' * k_j (with q + q' = 1 so every pixel is utilized, e.g., at 2.25 bpp, 75% of pixels embed 2 bits and 25% embed 3 bits), giving LSB and OPAP their strongest possible configuration.

Analysis of Tables 2 and 3 (Section 4, pp. 9–10): Table 2 (1.0 bpp, 262,144 bits): In LSB and OPAP with k = 1, all 262,144 pixels embed 1 bit each, and half of them (131,072 pixels) are modified by ±1, yielding MSE ≈ 0.500 and PSNR ≈ 51.14 dB. In our algorithm with n = 3 (EC_3 = 1.5 bpp), only ~174,763 pixels are needed; for each used pixel, the probability of zero change is 1/3 and the probability of ±1 change is 2/3, so only ~116,509 pixels change by ±1 (MSE ≈ 0.4444, PSNR ≈ 51.66 dB). Table 3 (1.5 bpp, 393,216 bits): Two baseline strategies are tested: k = 2 (using 0.75N = 196,608 pixels at 2 bpp) and k = 1.5 (first half of N pixels at k = 2, second half at k = 1). Even with the better k = 1.5 split, OPAP reaches 48.13 dB because half of the pixels suffer ±2 errors. Our n = 3 DEM keeps every pixel's change strictly within ±1, achieving 49.89–49.90 dB across all four images—completely independent of image texture!

Analysis of Table 4 (Section 4, pp. 10–11): Across all four test images (Lena, Baboon, Airplane, Pepper), the PSNR values at each capacity are remarkably consistent (within ±0.03 dB across images), confirming that the distortion depends primarily on the modulus alphabet n rather than host image texture. Key observations: - At exact powers of two (n = 4 for 2.0 bpp; n = 8 for 3.0 bpp), every codeword in DEM_t(n) has fixed length k = 2 or k = 3, and Eqs. (2)-(3) reduce mathematically to Chan & Cheng's OPAP (46.37 dB at 2 bpp; 40.73 dB at 3 bpp). - At every intermediate capacity (n = 5, 6, 7, 9, 10, 11, 13, 15), Proposed consistently outperforms OPAP by +0.18 to +0.97 dB and outperforms simple LSB by +2.2 to +3.5 dB, with the largest gains appearing right above power-of-two boundaries (e.g., n = 5 at 2.25 bpp: +0.97 dB; n = 11 at 3.375 bpp: +0.61 dB).

Theoretical Justification of Empirical Gains: For a uniformly distributed remainder modulo n, the expected mean square error of nearest-neighbor adjustment is: - For odd n = 2m + 1: MSE(n) = (2 * sum_{r=1}^{m} r^2) / n = (n^2 - 1) / 12. For n = 3: (9 - 1)/12 = 0.6667 -> PSNR = 10*log10(255^2 / 0.6667) = 49.89 dB (matches Table 3's 49.89 dB!). For n = 5: (25 - 1)/12 = 2.0000 -> PSNR = 10*log10(255^2 / 2.0) = 45.12 dB (matches Table 4's 45.12 dB!). - For even n = 2m: MSE(n) = (n^2 + 2) / 12. For n = 4 (OPAP k=2): (16 + 2)/12 = 1.5000 -> PSNR = 46.37 dB (matches Table 4!). For n = 8 (OPAP k=3): (64 + 2)/12 = 5.5000 -> PSNR = 40.73 dB (matches Table 4!). Meanwhile, OPAP at 2.25 bpp mixes 0.75 * 1.5 + 0.25 * 5.5 = 2.5000 -> PSNR = 44.15 dB, strictly worse than n = 5's MSE = 2.0000 (45.12 dB)! This closed-form analysis explains both the exact empirical numbers and why texture has negligible effect.

Summary of Contributions (Section 5): 1. Formulation of balanced prefix-free Directories of Elementary Messages (DEM_t(n)) with bit-dominance selection and closed-form expected capacity EC_n = floor(log2 n) - 1 + n / 2^{floor(log2 n)}. 2. Two-segment adaptive decomposition (M = M'_n || M''_{n-1}) paired with oversaturation-safe nearest-neighbor modulo adjustment (Eqs. 2–3), bounding pixel modification to at most floor(n/2). 3. Comprehensive empirical verification on 512x512 Lena, Baboon, Airplane, and Pepper across 1.0 to 3.875 bpp showing consistent superiority over simple LSB substitution everywhere and over OPAP at every non-power-of-two capacity.
