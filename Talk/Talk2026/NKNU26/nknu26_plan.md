一個 thread 的留言，標題是：很扯

昨天搭計程車的時候，發現司機大哥在聽 VK 科技閱讀講 NotebookLM
所以就跟他聊了起來，發現他也有聽曼報，甚至以前也有聽科技島讀，我也跟他分享以前的創業經歷
接著更加刷新三觀的是，他說他用 Claude Code vibe coding 做出了一個可以幫助他比較好算跑車收入的 app，還用 Typeless 搭配 Obsidian 串 agent 做了他個人的日記管理系統
我整個下巴快掉下來…..重點是他是一個全職計程車司機。還一直跟我說他覺得他 AI 用得沒有很好，他知道之後自己一定會被無人車取代，所以提早開始學習新科技
Oh my god！我跟他說，他的 AI 使用程度絕對是非常頂尖的，甚至贏過非常非常多年輕人跟上班族
我也覺得蠻激動的，感覺真的看到了那種科技平民化、AI 全民化的影子。AI 用得好真的不是要懂什麼艱深的工具或是專有名詞，而是能像這位司機大哥實際解決工作跟生活的問題，就是最完美的 100 分了
