# Teach - 薛念林教授課程教材庫

本儲存庫整合薛念林教授之多門大學與研究所課程教學教材、簡報、講義與範例程式碼。

---

## 課程結構

- **[TeachUX/](./TeachUX/)**：使用者體驗設計 (UX Design) 課程教材與簡報入口
- **[TeachSQA/](./TeachSQA/)**：軟體品質保證 (Software Quality Assurance) 課程教材、投影片與 Java 實作 Lab
- **[themes/](./themes/)**：跨課程共用 Marp 簡報主題樣式庫（含自我測驗互動回饋、課綱導航等樣式）
